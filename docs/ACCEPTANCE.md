# 开发构建 7 验收清单

本文件是待执行验收步骤，不是测试通过声明。当前版本名 `1.0.0-dev`，版本码以 `version.properties` 为准（本轮为 7）。只使用 `app-signed-development` 中的签名 APK；旧签名不一致且含重要记录时不要卸载。

## 云端检查

- 普通 CI 运行 release Kotlin 单元测试、Lint、Python 脚本测试，不打包或上传。
- 默认分支签名作业通过相同检查后用原有 Secrets 构建 APK，再验签；最终 Artifact 仅一个 APK。
- 生产 SQL 测试直接读取 EntrySql 常量与 DAO 修改语句，使用内存 SQLite；不能替代 Room 编译、迁移或 Android 仪器测试。本轮 schema 为 3，`MIGRATION_2_3` 与 `MIGRATION_1_2` 都尚未在真实数据库执行过。

## 升级与迁移

- [ ] 用开发构建 5（versionCode 5）创建日期、待办、分类与归档记录，覆盖安装本轮 APK：记录、分类、置顶、归档与备注全部保留。
- [ ] 从更早的构建 4（schema 1）直接升级，一次性执行 1→2→3：数据保留且新列为空（未分类、未置顶、未归档、无图标颜色）。
- [ ] 设置页显示版本码 6、包名 `local.daybook`、固定签名核对通过。
- [ ] 迁移失败不得静默删库：数据库无法打开时应显示明确错误，而不是空白列表。
- [ ] 覆盖安装后旧记录卡片使用类型默认图标与主题色，不显示错误的图标品牌。

## 外观设置

- [ ] 主题切换为浅色、深色、跟随系统：整界面即时变化，重启应用后保持。
- [ ] 字号小 / 默认 / 中 / 大四档切换后标题、正文与按钮同步缩放；再把系统字体调大，两者叠加仍可正常布局、不被底栏遮挡。
- [ ] 卡片密度切到紧凑后备注只显示一行，详情页仍能看到完整备注；切回标准恢复三行。
- [ ] 设置在旋转、进程被杀后仍保留（SharedPreferences 持久化）。

## 底栏入口

- [ ] 隐藏“任务”“待办”“统计”中的两项，底栏立即只显示剩余入口与设置；重启后保持。
- [ ] 尝试隐藏最后一项非设置入口时被拒绝，底栏不出现空条。
- [ ] 设置入口没有隐藏按钮，始终可达，点击可进入设置页。
- [ ] 用上移 / 下移调整顺序后底栏与宽屏侧栏顺序一致；当前所在入口被隐藏时界面回退到第一个可见入口而不是空白。

## 图标与主题色

- [ ] 编辑器“外观”分组选择图标与颜色，保存预览与列表卡片同步显示所选图标与色相。
- [ ] 再次点击已选图标或颜色可清除，卡片回到类型默认外观。
- [ ] 详情页显示“外观：图标名 · 颜色名”，与列表一致。
- [ ] 未知或旧数据的图标颜色不影响读取，按未设置显示。
- [ ] 深浅色主题下所选色相保持可辨识，不出现透明到无法阅读的文字。

## 分类侧栏与批量选择

- [ ] 720dp 宽屏：左侧出现分类侧栏，选择分类后列表与手机端分类胶囊结果一致；“管理分类”可打开分类弹窗。
- [ ] 归档视图下侧栏提示“不按分类筛选”，不显示可点击的分类项。
- [ ] 手机端长按卡片进入选择模式：操作条显示已选数量，点击其他卡片继续加选，取消选择可退出。
- [ ] “全选已加载”只选中当前已加载分页，不宣称全库全选。
- [ ] 批量移动到分类（含“未分类”）后列表与分类筛选结果一致，失败时显示错误而不是静默成功。
- [ ] 批量删除需二次确认；确认后选中记录消失，未选中的记录、分类与其他类型记录不受影响。
- [ ] 旋转屏幕或进程恢复后选择状态仍在，但已删除的记录不会残留在选择里。

## 日历面板（构建 7）

- [ ] 列表页日历默认展开：周视图显示 7 格，点击任意日期后列表筛选与卡片日数按该参考日计算；点“今天”回到今天。
- [ ] 切到“月”视图：显示完整月份 6 行网格，本月外日期淡化但仍可点击选择；上下翻月正常，2 月（含闰年）边界正确。
- [ ] 今天有描边高亮，选中日期为实心；再次确认选中日的 TalkBack 朗读包含日期、星期与“今天”标记。
- [ ] 点“收起”后日历折叠为一行，列表空间变大；重启或旋转后折叠状态与视图（周 / 月）保持。
- [ ] 归档视图与统计页不显示日历面板；周历只改参考日，不冒充按日期过滤记录。

## 新建类型面板（构建 7）

- [ ] 点击“新建”弹出底部 2 列类型面板：日期记录、待办可点，数值进度 / 计数 / 目标习惯 / 专注置灰并标注“未实现”。
- [ ] 点击未实现入口无反应、无假表单；点击日期或待办后直接进入对应编辑器，返回不再弹面板。
- [ ] 面板外点击或“取消”可关闭；键盘弹出时面板仍可完整操作。

## 操作反馈（构建 7）

- [ ] 置顶 / 取消置顶、归档、恢复、删除、勾选完成、新增 / 删除分类、批量移动 / 批量删除成功后，底部浮出一条确认消息，4 秒后自动消失，也可点“知道了”关闭。
- [ ] 连续触发同一操作不堆积重复消息；消息不遮挡底栏，TalkBack 能朗读消息内容。
- [ ] 操作失败（如存储异常）时只在页面内显示持久错误卡，不出现成功消息。
- [ ] 列表读取中显示统一加载卡；读取失败显示重试卡；空列表按“没有记录 / 条件过窄 / 还没有归档”显示对应文案。

## 兼容与隐私

- [ ] 深浅色、窄屏、横屏、200% 字体、键盘弹出下设置页、日历面板与批量操作条可完整操作。
- [ ] 离线可用，无登录、会员、行为追踪或新增权限；本轮不新增网络、存储或悬浮窗权限。
- [ ] 设置只保存外观与入口，不写业务数据；卸载仍会清空全部数据。

仍未实现：农历与重复规则、到期自动归档、月视图按日期任务标记（需要 occurrence 数据）、多选移入父任务、声音与振动开关、操作历史、备份恢复、提醒、小组件、应用锁、图片分享与更新检查。以上仍属正式版必做，不能将本构建当作全功能发布。

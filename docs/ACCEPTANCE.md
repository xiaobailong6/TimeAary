# 开发构建 4 验收清单

本文件是待执行验收步骤，不是测试通过声明。当前版本名 `1.0.0-dev`，版本码以 `version.properties` 为准。只使用 `app-signed-development` 中的签名 APK；旧签名不一致且含重要记录时不要卸载。

## 云端检查

- 普通 CI 运行 release Kotlin 单元测试、Lint、Python 脚本测试，不打包或上传。
- 默认分支签名作业通过相同检查后用原有 Secrets 构建 APK，再验签；最终 Artifact 仅一个 APK。
- 生产 SQL 测试直接读取 EntrySql 中常量和 DAO 修改语句，使用内存 SQLite；不能替代 Room 编译、迁移或 Android 仪器测试。

## 基础操作与详情

- [ ] 先覆盖安装开发版，原有日期与待办记录仍存在；设置中显示版本码 4、固定证书核对通过。
- [ ] 新建一条日期记录，填写长备注；列表只显示摘要，点击卡片或更多 → 查看详情可读完整备注。
- [ ] 从详情编辑标题 / 日期 / 备注，保存后回到同一详情，内容实时刷新；返回列表后同样更新。
- [ ] 从详情完成待办，再设为未完成，详情、列表和统计结果一致。
- [ ] 列表和详情删除均需确认，取消不丢数据；删除成功后详情退出。存储失败时有持久错误而非静默成功。
- [ ] 分享文字摘要先确认字段，默认不含备注；选择包含备注后才带入系统分享，无接收应用时显示错误。
- [ ] 编辑未保存时返回仍提示；旋转屏幕 / 进程恢复保留草稿和稳定 ID，不重复创建。

## 搜索、筛选与排序

- [ ] 创建日期昨天 / 今天 / 明天三条，使用当天 / 过去 / 未来筛选，边界正确；周历改参考日后筛选及日数同口径。
- [ ] 待办全部 / 未完成 / 已完成 / 当天 / 逾期未完成能组合搜索；逾期不包括今天，也不包括已完成项。
- [ ] 搜索匹配标题或备注中的中文子串，英文 ASCII 忽略大小写；`%`、`_` 和引号按普通字符处理。
- [ ] 记录超过 30 条仍能搜索最后一条，不只过滤已加载页；无结果显示清除条件入口。
- [ ] 日期早到晚 / 晚到早 / 标题排序生效，相同值保持 ID 稳定顺序；待办未完成始终优先、组内排序。
- [ ] 日期页和待办页的关键词、筛选、排序互不混用；旋转与进程恢复保留条件。重置恢复全部、日期升序、无关键词。
- [ ] 快速连续输入、清空、切页不会让另一类型记录被错误操作，结果加载与失败重试可见。

## 真实统计

- [ ] 全局日期总数、待办总数、当前完成数、逾期未完成数和完成比例来自全部数据库记录，不受列表筛选或分页影响。
- [ ] 没有待办时显示 0%，不除零。完成 / 反选 / 编辑计划日期 / 删除后指标同步。
- [ ] 周 / 月 / 年切换、前后翻页和回到当前期间有效；闰年 2 月含 29 天，周可跨年，年图为 12 个月。
- [ ] 柱图补齐无数据日，各柱点击可查看日期 / 待办 / 当前完成数量，TalkBack 能读数值。
- [ ] 快速翻期不把上个期间的数据画在新标题下，读取失败显示重试，不把失败当零。
- [ ] 口径说明始终可见：柱图按原始日期 / 计划日期聚合，当前已完成不代表历史实际完成时刻，也没有专注时长、连续打卡或操作历史。

## 兼容与隐私

- [ ] 深浅色、窄屏、横屏、720dp 宽屏导航、200% 字体、键盘弹出下仍可完成关键操作，无底栏遮挡。
- [ ] 离线可用，无登录、会员、行为追踪或额外权限；文字分享只在用户确认后发送到系统分享面板。
- [ ] 本轮数据库 schema 仍为 1，不使用破坏性迁移；SQL CASE 排序与子串搜索尚未进行十万级性能验收，不宣称达标。

仍未实现：农历、重复、分类、置顶、归档、数值任务、父子任务、专注、备份恢复、提醒、小组件、图片分享、操作历史及完整设置。以上仍属正式版必做，不能将本构建当作全功能发布。
